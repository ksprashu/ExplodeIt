# Core Data Contracts & TypeScript Domain Models

## Overview
ExplodeIt relies on strongly typed domain contracts declared in `types.ts`. These contracts define the state machine phases, the structured JSON output schema generated by Gemini models, token usage telemetry records, and persistent generation items.

## Domain Model Taxonomy

### 1. Generation Status State Machine (`GenerationStatus`)
An enumeration defining the precise granular lifecycle of a generation request:

```typescript
export enum GenerationStatus {
  IDLE = 'IDLE',                                      // System ready for user input
  GENERATING_RANDOM = 'GENERATING_RANDOM',            // "Surprise Me" ideation via Gemini 2.5 Flash
  PLANNING = 'PLANNING',                              // Blueprint structuring via Gemini 3 Pro
  GENERATING_INFOGRAPHIC = 'GENERATING_INFOGRAPHIC',  // Exploded infographic rendering via Gemini 3 Pro Image
  GENERATING_ASSEMBLY = 'GENERATING_ASSEMBLY',        // Assembled product shot via Gemini 3 Pro Image (Image-to-Image)
  ENRICHING = 'ENRICHING',                            // Deep technical authoring via Gemini 2.5 Flash + Search
  ANIMATING = 'ANIMATING',                            // Cinematic assembly video via Veo 3.1 & TTS audio
  COMPLETED = 'COMPLETED',                            // Pipeline finished; full explorer UI interactive
  FAILED = 'FAILED',                                  // Interrupted by network, auth, or schema validation error
}
```

### 2. Deconstructed Component (`ComponentPart`)
Represents an individual sub-part, layer, module, or cognitive principle identified in the topic:

```typescript
export interface ComponentPart {
  name: string;               // Clean title (e.g. "Sensor Matrix", "Relational Database")
  shortDescription: string;   // High-level single sentence summary
  detailedContent?: string;   // Multi-paragraph deep technical dive enriched via search
  composition: string;        // Material, framework, language, or metaphysical foundation
  sources?: string[];         // Verified citations extracted from Google Search Grounding metadata
}
```

### 3. Structural Blueprint Plan (`ObjectPlan`)
The foundational document produced during Phase 1 by Gemini 3 Pro, guiding all downstream image generation, video rendering, and authoring:

```typescript
export interface ObjectPlan {
  displayTitle: string;
  category: string;
  domainType: 'PHYSICAL' | 'SOFTWARE' | 'CONCEPTUAL' | 'BIOLOGICAL' | 'OTHER';
  visualMetaphor: string; // Dynamic diagram style (e.g. "Exploded View", "System Architecture", "Mind Map")
  sectionTitles: {
    origin: string;       // Dynamic label (e.g. "Historical Genesis", "Architectural Inception")
    anatomy: string;      // Dynamic label (e.g. "Mechanical Anatomy", "Component Topology")
    article: string;      // Dynamic label (e.g. "Engineering Analysis", "Operating Theory")
    trivia: string;       // Dynamic label (e.g. "Curiosities & Facts", "Edge Cases")
  };
  originStory: string;    // ~100-word concise contextual genesis
  detailedArticle: string;// ~800-word markdown formatted comprehensive entry
  trivia: string[];       // Array of 5 verified surprising facts
  visualStylePrompt: string; // Tailored styling directives passed to Image models
  componentList: string[];   // Array of 6-8 canonical component names
  audioVibe: {
    voiceName: string;       // Prebuilt voice: 'Puck' | 'Charon' | 'Kore' | 'Fenrir' | 'Zephyr'
    toneDescription: string; // Mood and pacing guidance
  };
}
```

### 4. Telemetry & Cost Accounting (`TokenUsage`)
Tracks token consumption and financial expenditure for each discrete model invocation:

```typescript
export interface TokenUsage {
  model: string;          // Model ID (e.g. "gemini-3-pro-preview", "veo-3.1-generate-preview")
  inputTokens: number;    // Prompt tokens consumed
  outputTokens: number;   // Candidate response tokens generated
  costEstimate: number;   // Estimated cost in USD
}
```

### 5. Persistent Session Entity (`GenerationItem`)
The composite entity representing a complete exploration session, maintained in application history:

```typescript
export interface GenerationItem {
  id: string;             // Epoch timestamp identifier
  prompt: string;         // User query string
  timestamp: number;      // Generation start time in milliseconds
  
  // Data State
  plan: ObjectPlan | null;
  components: ComponentPart[]; // Populated incrementally across pipeline stages
  narrationScript: string | null;
  
  // Visual & Audio Assets
  infographicUrl: string | null;  // Data URL for exploded view
  assembledUrl: string | null;    // Data URL for assembled shot
  videoUrl: string | null;        // Blob URL for Veo video
  audioUrl: string | null;        // Blob URL for WAV narration
  hasVideo: boolean;              // Whether video generation was requested
  
  usage: TokenUsage[];            // Cumulative token and cost records
}
```

### 6. Model Tier Architecture (`ModelTier` & `StageModelConfig`)
Defines the multi-tiered model selector and per-stage configuration:

```typescript
export type ModelTier = 'pro' | 'budget' | 'custom';

export interface StageModelConfig {
  planning: string;

  assembled: string;
  enriching: string;
  video: string;
  narration: string;
  enableVideo: boolean;

export interface ModelPricingEntry {
  id: string;
  displayName: string;
  type: 'token' | 'image' | 'video' | 'tts';

    inputPer1kTokens?: number;
    outputPer1kTokens?: number;
    perImage?: number;
    perVideo?: number;
    per1kChars?: number;

```

### 7. Community Contribution Contracts (`SanitizedGenerationBundle` & `CommunityCatalogItem`)
Ensures clean serialization and indexing for public showcase items:

```typescript
export interface SanitizedGenerationBundle {
  manifest: {
    id: string;
    topic: string;
    timestamp: string;
    domain: string;
    metaphor: string;
    modelTier: ModelTier;
    modelsUsed: Partial<StageModelConfig>;
  };
  plan: ObjectPlan;
  components: ComponentPart[];
  narrationScript: string;
  media: {
    infographicBlob: Blob;
    assembledBlob: Blob;
    videoBlob?: Blob;
    audioBlob: Blob;
  };
}

export interface CommunityCatalogItem {
  id: string;
  topic: string;
  timestamp: string;
  domain: string;
  metaphor: string;
  componentCount: number;
  hasVideo: boolean;
  hasAudio: boolean;
  modelTier: ModelTier;
  previewUrl: string;

}
```
